# 806 E Ramseur Mini Golf + Bar — Business Plan

Static HTML business plan for a mini golf course + bar at 806 E Ramseur St, Durham, NC.

| Page | File |
|---|---|
| Property | `index.html` |
| Competitive Analysis | `competition.html` |
| Issues | `issues.html` |
| Revenue Estimates (interactive) | `revenue.html` |
| Expenses | `expenses.html` |
| Labor | `labor.html` |

All pages share `styles.css`. The P&L model is `806-Ramseur-PnL.xlsx`.

## View locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.

**Note:** GitHub Pages sites are public, even from a private repo on most plans. Keep the repo/site private if the plan is confidential.
